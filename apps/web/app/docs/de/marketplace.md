# Marktplatz

Der izan.io-Marktplatz auf [zihin.io](https://zihin.io) ist eine Community-Plattform zum Teilen und Entdecken von Browser-Automatisierungstools.

## Tools durchsuchen

Besuchen Sie [zihin.io](https://zihin.io), um verfuegbare Tools zu erkunden. Sie koennen:

- Nach Kategorie filtern (Produktivitaet, Datenextraktion, soziale Medien usw.)
- Nach Name oder Stichwort suchen
- Tool-Details anzeigen, einschliesslich Beschreibung, Parameter und Quellcode

Alle Tools sind Open Source und ihr Code ist vor der Installation einsehbar.

## Tool installieren

So installieren Sie ein Tool vom Marktplatz:

1. Finden Sie das Tool auf [zihin.io](https://zihin.io)
2. Klicken Sie auf **Installieren**
3. Das Tool wird automatisch zu Ihrer Chrome-Erweiterung hinzugefuegt

Installierte Tools erscheinen im Seitenpanel der Erweiterung und sind sofort fuer MCP-Clients verfuegbar.

## Tool einreichen

Sie koennen Ihre Tools mit der Community teilen:

1. Erstellen Sie Ihr Tool in der izan.io Chrome-Erweiterung
2. Testen Sie es gruendlich
3. Gehen Sie zum [zihin.io GitHub-Repository](https://github.com/nicekid1/zihin.io)
4. Oeffnen Sie einen Pull Request mit Ihrer Tool-Definition
5. Die Community prueft und merged Ihren Beitrag

### Einreichungsrichtlinien

- Geben Sie einen klaren Namen und eine Beschreibung an
- Dokumentieren Sie alle Parameter
- Stellen Sie sicher, dass das Tool zuverlaessig bei verschiedenen Seitenzustaenden funktioniert
- Vermeiden Sie Tools, die Authentifizierungsdaten als Parameter erfordern
