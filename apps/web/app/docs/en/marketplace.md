# Marketplace

The izan.io marketplace at [zihin.io](https://zihin.io) is a community hub for sharing and discovering browser automation tools.

## Browsing Tools

Visit [zihin.io](https://zihin.io) to explore available tools. You can:

- Browse by category (productivity, data extraction, social media, etc.)
- Search by name or keyword
- View tool details, including description, parameters, and source code

All tools are open source and their code is visible before installation.

## Installing a Tool

To install a tool from the marketplace:

1. Find the tool on [zihin.io](https://zihin.io)
2. Click **Install**
3. The tool is added to your Chrome extension automatically

Installed tools appear in the extension side panel and are immediately available to MCP clients.

## Submitting a Tool

You can share your tools with the community by submitting them to the marketplace:

1. Create your tool in the izan.io Chrome extension
2. Test it thoroughly
3. Go to the [zihin.io GitHub repository](https://github.com/nicekid1/zihin.io)
4. Open a pull request with your tool definition
5. The community reviews and merges your submission

### Submission Guidelines

- Include a clear name and description
- Document all parameters
- Make sure the tool works reliably across different page states
- Avoid tools that require authentication credentials as parameters
